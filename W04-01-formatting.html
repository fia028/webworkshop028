แบบฝึกปฏิบัติ: HTML Formatting

เรียนรู้การจัดรูปแบบข้อความด้วยแท็ก HTML พร้อมด้วยตัวอย่างและการตกแต่งด้วย CSS

📄 ตัวอย่างผลลัพธ์

B: ข้อความตัวหนา

STRONG: ข้อความสำคัญ

I: ข้อความตัวเอียง

EM: ข้อความเน้นเสียง

U: ข้อความขีดเส้นใต้

MARK: ข้อความที่ถูกเน้น

SMALL: ข้อความขนาดเล็ก

DEL: ข้อความที่ถูกลบ

SUP: X2

SUB: H2O

</> ตัวอย่างโค้ด HTML

<b>ข้อความตัวหนา</b>
<strong>ข้อความสำคัญ</strong>
<i>ข้อความตัวเอียง</i>
<em>ข้อความเน้นเสียง</em>
<u>ข้อความขีดเส้นใต้</u>
<mark>ข้อความที่ถูกเน้น</mark>
<small>ข้อความขนาดเล็ก</small>
<del>ข้อความที่ถูกลบ</del>
X<sup>2</sup>
H<sub>2</sub>O

🎯 กิจกรรมฝึกปฏิบัติ

✓ พิมพ์ข้อความสร้างหน้าเว็บ 1 หน้า

✓ ใช้แท็ก Formatting อย่างน้อย 6 รูปแบบ

✓ ทดลองเปรียบเทียบ <b> กับ <strong>

✓ ทดลองเปรียบเทียบ <i> กับ <em>

✓ ปรับสี ขนาด และพื้นหลังด้วย CSS

✓ บันทึกไฟล์ชื่อ formatting.html

💡 เกร็ดความรู้

แท็กจัดรูปแบบข้อความช่วยให้เนื้อหาสื่อสารชัดเจนและมีความหมายมากขึ้น เช่น <strong> ใช้สำหรับข้อความสำคัญ, <em> ใช้เน้นความสำคัญหรืออารมณ์ และ <mark> ใช้เน้นข้อความที่ต้องการให้โดดเด่น ซึ่งช่วยให้ผู้ใช้งานเข้าใจเนื้อหาได้ง่ายและเป็นระเบียบมากขึ้น
